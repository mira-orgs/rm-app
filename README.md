# MIRA RM app

The screens of the MIRA RM app, served at https://mira-orgs.github.io/rm-app/.

This repository holds only the published screens (HTML, CSS, JavaScript). It contains no
Salesforce data and no secret: every user signs in with their own Salesforce login, and all
data is read from Salesforce after sign-in.

The files here are published from the main project. Do not edit them here.
